# JournalApp

JournalApp is a Spring Boot REST API for managing personal journal entries. It allows users to create, update, view, and delete journal entries securely.

## Features

- User Registration and Login
- JWT Authentication
- Role-Based Access (User/Admin)
- CRUD Operations for Journal Entries
- MongoDB Integration

## Tech Stack

- Java
- Spring Boot
- Spring Security
- MongoDB
- JWT



## Main APIs

### User
- Register
- Login
- Update Profile
- Delete User

### Journal
- Create Entry
- Get All Entries
- Get Entry by ID
- Update Entry
- Delete Entry

### Admin
- Get All Users
- Create Admin User

## Database

MongoDB is used to store user information and journal entries.
